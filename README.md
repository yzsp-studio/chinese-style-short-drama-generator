## 🇬🇧 English

An end-to-end workflow that turns a Chinese-style short-drama idea or single-episode script into a watchable finished episode. Two entry groups split into four small tab cards covering script status, 9:16 or 16:9 framing, character references, and visual direction — never merged, never chosen for you. With a script it reads it in; without one it first runs single-episode writing. It then produces a storyboard outline, multi-angle character sheets, character-free scene reference sheets, 2x4 monochrome storyboard panels, and panel-level video prompts, before generating clips and assembling the finished episode. Built-in Chinese-style and xianxia aesthetics plus full AI expression and natural-blink performance logic.

### ✨ What it does

- Confirms script status, framing, character references, and style direction through four separate tab cards
- Runs single-episode writing first when no script exists, then continues into the storyboard stage
- Outputs multi-angle character sheets and character-free scene reference sheets for cross-shot consistency
- Builds 2x4 monochrome storyboard panels and converts them into panel-level video prompts
- Ships Chinese-style and xianxia aesthetics with full AI expression and natural-blink performance logic
- Carries the chain from prompts to clips to final assembly into a watchable episode
